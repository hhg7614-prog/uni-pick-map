# UNI PICK 뉴스 시스템 4단계 저장 보고서

이번 단계는 3단계에서 받은 게시물을 화면에 보여주지 않고, 개발용 누적 저장소에 안전하게 넣는 작업입니다. 같은 게시물은 URL과 해시를 비교해서 다시 넣지 않습니다.

- 입력: 13개
- 검증 통과: 13개
- 새로 저장: 0개
- 확정 중복: 13개
- 사람이 확인할 중복 후보: 0개
- 제외된 항목: 0개
- 저장소: 13개 → 13개

## 중복 기준

1. 정규화한 원문 URL이 같으면 확정 중복입니다.
2. URL 해시가 같으면 확정 중복입니다.
3. 같은 대학·카테고리·제목·날짜의 내용 해시가 같으면 확정 중복입니다.
4. URL은 달라도 제목이 거의 같고 날짜가 하루 이내이면 사람이 확인할 후보로만 기록하고 저장하지 않습니다.

## 안전 장치

저장 전 기존 파일을 개발용 백업 폴더에 복사하고, 임시 파일을 검증한 뒤 교체합니다. JSON이 깨진 경우에는 기존 파일을 덮어쓰지 않고 오류를 알려줍니다.

기존 UNI PICK 지도와 학교 소식 화면은 이 저장소를 읽지 않습니다.
