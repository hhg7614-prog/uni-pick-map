# UNI PICK 대학 소식 개발 폴더 — 1단계

이 폴더는 전국 대학 소식을 안전하게 수집하기 전에 필요한 **설계와 검사 도구**를 모아 둔 개발 전용 공간입니다. 현재 UNI PICK 화면, 지도, 학교 검색, 기존 학교 소식 카드와는 연결되어 있지 않습니다.

## 지금 이 폴더가 하는 일

- 학교 소식, 공지사항, 뉴스 기사, 행사 소식의 공통 분류를 정합니다.
- 나중에 저장할 소식 항목과 대학별 출처 설정의 형태를 정합니다.
- 예시 데이터가 올바른 형태인지 검사하는 함수만 제공합니다.

## 지금 하지 않는 일

- 실제 대학 사이트 접속, RSS 요청, HTML 수집, Playwright 실행
- AI 요약, 데이터베이스 저장, 자동 업데이트, 스케줄러·cron 실행
- 현재 웹사이트 화면의 데이터나 UI 변경

## 네 가지 소식 유형

| 값 | 화면용 이름 | 뜻 |
| --- | --- | --- |
| `school_news` | 학교 소식 | 대학이 직접 알린 일반 소식 |
| `school_notice` | 학교 공지사항 | 학사·행정 공지 |
| `media_news` | 뉴스 기사 | 언론 등 외부 매체 기사 |
| `school_event` | 행사 소식 | 행사·설명회·캠퍼스 이벤트 |

## 파일 안내

- `constants/news-categories.js`: 공통 분류와 확인 함수
- `models/`: 소식 항목·출처 설정의 기본 형태
- `utils/`: 필수 값, 분류, 날짜, URL 형식 검사
- `config/`: 모든 실행 기능이 꺼진 설정 예시
- `data/`: 실제 주소를 넣지 않은 예시 데이터
- `reports/`: 나중에 사람이 확인할 보고서를 둘 빈 폴더

## 왜 enabled가 false인가요?

1단계는 현재 사이트를 안전하게 유지하는 단계입니다. 실제 주소와 이용 조건이 확인되기 전에는 수집을 시작하면 안 되므로 모든 예시의 `enabled`는 `false`입니다.

## 이후 단계

1. 소수 대학의 공식 출처를 사람이 확인합니다.
2. 확인된 주소와 사용 조건을 출처 설정에 기록합니다.
3. 별도의 수집 기능을 검토하고 연결합니다.
4. 수집 결과를 검토한 뒤에만 화면 연결을 논의합니다.

## 오류가 날 때

- JSON의 쉼표와 따옴표를 확인합니다.
- `category`, `sourceType`, `status`가 허용 값인지 확인합니다.
- 실행을 켜려는 설정에는 실제 검증 URL이 있는지 확인합니다.
- 1단계에서는 어떤 실행 설정도 켜지지 않아야 합니다.

## 1단계 확인 방법

UNI PICK을 열어 지도·대학 마커·검색·학교 정보 카드·기존 학교 소식 카드가 이전과 똑같이 보이면 정상입니다. 이 폴더는 웹사이트에서 불러오지 않으므로 네트워크 요청이나 자동 수집이 발생하지 않습니다.
