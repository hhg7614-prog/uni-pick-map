# UNI PICK Claude Code instructions

Before planning or changing this project, read `AGENTS.md` in full and follow it.

For a development improvement request, use the `/ship` workflow:
`Planner -> Coder -> Tester -> Reviewer`.

Keep development workflow records in `.pipeline/`. Do not automatically deploy, commit, push, or change production data unless the user explicitly requests it and the checks defined in `AGENTS.md` pass.
